# Zjištění a doporučení

## 1. Shrnutí

**V září 2026 podnik nesplnil výrobní plán, překročil náklady odpovídající dosažené výrobě a dosáhl výrazně nižšího zisku proti plánu. Zásoby přitom převyšují plán.**

| Oblast | Hlavní zjištění |
|---|---|
| Výroba | Plnění **94,02 % v NH**; proti plánu chybělo **96,16 NH**. |
| Náklady | Nepříznivá výrobní nákladová odchylka **269 443,34 Kč**. |
| Prioritní středisko | **S02:** nejvyšší nákladová odchylka a COPQ, nejnižší OEE. |
| Provoz | OEE **66,58 %**, proti **70,76 %** v lednu. |
| Ziskovost | Zisk **45 801,31 Kč** proti plánu **474 323,44 Kč**; marže **1,41 %**. |
| Zásoby | Hodnota materiálu, rozpracovanosti a hotových výrobků celkem přibližně **833,9 tis. Kč nad plánem**. |
| Výhled | Roční nákladová prognóza **33,42 mil. Kč**, překročení plánu **1,62 mil. Kč / 5,10 %**. |

**Priority:** prověřit provozní ztráty S02, cenovou odchylku materiálu a vyšší pracnost; sladit výrobu s očekávaným prodejem a zásobami.
